## 2. 核心场景的整理草稿（助手整理）

> 帮助都匀市的学生，在完成日常练习、作业或考试后的复盘中，结合教材范围和连续学习表现，逐步了解疑似薄弱环节，并调整接下来学什么、怎样巩固。

初中、高中为当前切入偏好，首个年级、学科和具体使用时刻仍未确定。这句话用于继续讨论 Q1，不替代目标用户需求证据。

“动态”可以先理解为下面的候选流程，而不是一次上传后生成固定报告：

1. 确认当前教材范围、课堂进度和本次任务，取得允许使用的学习材料与表现记录。
2. 根据本次作答及可获得的过程提出暂时判断，标明依据和不确定之处。
3. 给出可执行的下一步建议，例如巩固一个前置概念、调整练习类型，或暂缓下结论。
4. 随后续正常练习、订正及必要的验证更新判断，再调整建议。

输入可以来自已有学校作业与练习，不预设学生必须额外完成整套诊断题。“考试情况”不预设为导入完整试卷；可获取、可处理的材料范围仍待核实。导入教材用于确定学习范围，不能单凭教材判断个人掌握情况。

## 3. 动态调整怎样体现（助手虚构示例）

以下仅用于说明讨论中的体验，不是真实学生记录，不代表已实现功能或已选定数学为首发学科。

| 时间 | 新获得的表现 | 暂时判断如何更新 | 下一步建议如何变化 |
| --- | --- | --- | --- |
| 第一天 | 作业出现展开括号错误，已有步骤可供核对 | 怀疑分配律使用不完整；先核对识别和抄写问题，证据不足以确定原因 | 围绕展开过程进行简短核对，再决定是否需要巩固 |
| 第二天 | 订正后的原题做对，但此前看过答案 | 记录订正完成；尚不能据此确认能独立应用 | 从后续练习中观察同类新题，必要时提供少量验证任务 |
| 第三天 | 独立完成同类新题，另有移项步骤出错 | 下调对展开问题的担忧，新增移项问题的疑点；仍需后续观察 | 减少重复展开练习，按新证据调整下一项巩固任务 |

需要验证的是：这些变化是否比老师、学生现有办法更有帮助，是否减少重复无效练习，以及取得这些证据是否增加负担。不能仅以上传量、对话次数或一次答对认定有效。

## 4. 长期记录与上下文管理（助手整理，未定实现）

成员提出的上下文问题，可以先从产品需要保留什么来讨论：

| 记录内容 | 需要能回答的问题 |
| --- | --- |
| 学习事实 | 何时做了什么任务，原始作答是什么，是否看过答案或使用提示，材料识别是否经过核对？ |
| 当前判断及依据 | 哪些是疑点，哪些得到多次独立任务支持；依据哪些记录，何时被新证据修正？ |
| 学习安排与反馈 | 推荐过什么、为什么推荐，学生是否执行，后续表现怎样，是否需要调整？ |
| 人工更正 | 学生、教师或家长是否纠正过识别或分析，旧判断是否随之修正？ |

保存方式、保存期限、身份与权限、向模型提供哪些上下文、成本和删除方式仍未设计。以上不是要求把全部历史对话持续拼接，也不是已经确定数据库或模型架构。

DeepSeek 仅为用户提出的模型候选。应先用不含学生个人信息的模拟材料明确需要检验的任务，再比较分析准确性、材料处理能力、延迟与费用；目前未做模型评测，不预设某一模型能完成全部环节。

## 5. 指南与实际入口需要一起考虑

[指南原文](../../references/中小学生成式人工智能使用指南（2025年版）.md)第 2–3 页的个性化学习场景，涉及学习进程管理、动态推荐和反馈更新，可作为本次构思的参考。场景描述不等于对具体产品效果或进校资格的认可。

指南第 2 页区分学段使用边界，第 7–9 页涉及进校准入、教师指导、隐私和资源授权。产品入口需结合这些要求与当地实际核实，不能由“学生受益”直接推出“学生独自操作开放式 AI”。

当前仍需分别讨论：谁受益、谁提供材料、谁查看或修正分析、谁组织使用、谁付费。校内设备或纸面任务、家庭设备与小程序均可继续构思；入口和参与者未确定，不因此直接改成教师端产品。

## 6. 下一轮可以具体讨论的问题（助手建议）

1. 先围绕哪一种时刻构思：日常作业后、订正后仍不会、阶段考试复盘，还是按教材规划下一章？
2. 最少需要哪些连续记录，才能给出有依据的建议？学生如何低负担提供已有解题过程？
3. 第一屏是否先呈现“接下来做什么、为什么、完成后怎样调整”？可先用模拟材料演示连续三天建议如何变化。
4. 学生没有校内手机时，选择什么设备、时段和组织方式？家长与教师各承担多少操作？
5. “智能学伴”这个提议里，最值得先验证的是分析、学习建议还是持续执行？订阅是否有对应的持续价值？

上述为讨论建议；是否制作示例原型、由谁完成和何时验证仍待团队安排。现阶段仍缺真实需求案例、访谈反馈、持续使用和付费证据。
