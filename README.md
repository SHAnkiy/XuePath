# XuePath

XuePath 正在探索面向中国本地县城中小学的 AI 教学与学习辅助产品，希望未来能向学校提供产品或服务并探索收费。当前主要用于尝试、练手和验证想法，处于初步产品探索与头脑风暴阶段。

当前重点探索的使用场景是：**根据学生的学习情况，持续调整接下来的学习方向。**

本文描述产品构想与讨论状态，不代表已经实现的功能。

## 当前构想

- **拟服务对象与潜在客户**：本地县城中小学；目前表达了向学校提供产品或服务的意向，尚未形成订单或确定采购方式。
- **使用者**：此前构想重点在中小学生，老师、学校及家长如何参与、谁实际付费仍待验证。
- **学生端形态**：倾向微信小程序。
- **学习材料**：考虑导入教材、日常作业、错题及已有解题过程。
- **个性化支持**：探索如何基于个人学习证据，帮助纠错、识别疑似知识漏洞并调整学习安排。
- **商业偏好**：倾向 SaaS 订阅，订阅包含一定 credits，额外用量可以购买；发起人希望由家长付费（2026-10-08），尚未验证。具体计量、额度与价格尚未确定。
- **现有资源**：可接触县级中小学的老师或校方，学段、学科有选择空间；尚未开展校方需求访谈。

## 接下来要讨论的重点

1. “学习方向”主要指一门学科内的学习顺序，还是多个学科之间的时间与精力分配？
2. “普适性”的具体缺口在哪里：设备和费用门槛、教材适配、学习基础差异，还是学习时间与使用条件？
3. 系统依据什么证据调整建议，又如何确认调整对学生有帮助？
4. 学生、家长、老师和学校分别需要什么价值，谁会实际付费？
